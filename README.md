## 📖 About The Project

This portfolio is built **from scratch** using HTML5, Vanilla CSS, and JavaScript — no frameworks, no shortcuts. It features glassmorphism UI, scroll-reveal animations, a dark/light mode toggle, custom cursor, and a fully working contact form.

### ✨ Key Features

| Feature | Description |
|---|---|
| 🎨 **Premium UI/UX** | Glassmorphism effects, gradient text, ambient orbs, and custom cursor |
| 🌙 **Dark / Light Mode** | Theme toggle with user preference memory |
| 📱 **Fully Responsive** | Works flawlessly on desktop, tablet, and mobile |
| ⚡ **Smooth Animations** | Scroll reveals, typed text, floating elements, and micro-interactions |
| ♿ **Accessible & SEO** | Semantic HTML5, proper meta tags, and Open Graph support |
| 📬 **Contact Form** | Integrated message form with validation and status feedback |
| 🚀 **Page Loader** | Cinematic curtain-style page loader with progress bar |

## ⚙️ How to Run Locally

**Prerequisites:** A modern web browser (Chrome, Firefox, Edge)

```bash
# 1. Clone the repository
git clone https://github.com/Sejalsoni30/Sejal-Portfolio.git

# 2. Navigate into the project directory
cd Sejal-Portfolio

# 3a. Open directly in browser — double-click index.html  OR

# 3b. Use a local dev server (recommended)
npx serve .
```

> 💡 **Tip:** Using VS Code? Install the **Live Server** extension and click *"Go Live"* for hot-reload on file changes.
